# Minecraft Fate · 英雄王与骑士王 · King of Heroes & King of Knights

[![Minecraft](https://img.shields.io/badge/Minecraft-26.3-62B47A)](https://www.minecraft.net/)
[![Loader](https://img.shields.io/badge/Loader-Fabric-DBD0B4)](https://fabricmc.net/)
[![Java](https://img.shields.io/badge/Java-25-ED8B00)](https://adoptium.net/)
[![License](https://img.shields.io/badge/License-MIT-blue)](LICENSE)
[![Release](https://img.shields.io/github/v/release/RoyceBella-commits/fate-kings)](https://github.com/RoyceBella-commits/fate-kings/releases/latest)

一个只做两个人的 Fate Fabric Mod：**英雄王吉尔伽美什**和**骑士王阿尔托利亚（Saber）**。两人的能力各自绑定在一套铠甲上：穿齐黄金铠甲就是英雄王，穿齐骑士王铠甲就是骑士王。技能不放轮盘，全部做成右键使用的道具，拿到就是满级。可以和[「咒术回战：五条悟 × 宿傩」](https://github.com/RoyceBella-commits/jjk-gojo-sukuna) Mod 同装：乖离剑 Ea 和誓约胜利之剑是仅有的两种能直接穿透无下限的攻击，两者都能一击秒杀魔虚罗；誓约胜利之剑秒杀原版一切生物，但打五条悟只打残、不打死。两个 NPC 是死敌，相遇必战，重演 Fate 线最终战"Ea 压过圣剑 → 理想乡挡下 Ea → 圣剑反击"。

> *English:* A focused Fate Fabric mod with exactly two kings. Wear the golden armour to become Gilgamesh (Gate of Babylon, Bab-ilu and Ea's Enuma Elish, Enkidu, Vimana, flight) or the knight's armour to become Artoria (Excalibur with Invisible Air, Strike Air, Mana Burst leaps and charges, the true name, and Avalon's three layers). Everything is a right-click item at full power. Both NPCs are rivals and clash noble phantasms. Soft-compatible with the JJK Gojo × Sukuna mod: only Ea and Excalibur pierce Infinity, both kill Mahoraga outright, and Excalibur leaves Gojo at one heart instead of killing him.

## 📥 安装

需要：

| 组件 | 版本 |
|---|---|
| Minecraft Java 版 | 26.3 |
| [Fabric Loader](https://fabricmc.net/use/installer/) | 0.19.5 或更高 |
| [Fabric API](https://modrinth.com/mod/fabric-api) | 0.161.0+26.3 |
| Java | 25（官方启动器会自动提供） |
| [「咒术回战：五条悟 × 宿傩」](https://github.com/RoyceBella-commits/jjk-gojo-sukuna) | 可选，2.2.2 – 2.2.4 已适配 |

步骤：

1. 用 [Fabric 安装器](https://fabricmc.net/use/installer/)为 Minecraft 26.3 安装 Fabric Loader。
2. 从 [Releases](https://github.com/RoyceBella-commits/fate-kings/releases/latest) 下载 `fate-kings-1.0.1+mc26.3.jar`。
3. 把它和 Fabric API 一起放进游戏目录的 `mods` 文件夹（Windows 默认是 `%APPDATA%\.minecraft\mods`）。想打"Fate vs 咒术回战"，再从[宿傩 Mod 的 Releases](https://github.com/RoyceBella-commits/jjk-gojo-sukuna/releases/latest) 下载它的 JAR 一起放进去。
4. 用 Fabric 配置启动。第一次建议新建超平坦世界试玩：Ea 和圣剑会破坏地形（可以关，见下文）。

**多人服务器**：服务端和所有客户端都要装同一版本。
**从旧版本升级**：先删掉旧 JAR（Mod ID 相同，同时放两个会报错），旧存档可以继续用；旧存档里的 NPC 会自动升到 200 血。

## 🎮 玩法

### 两套铠甲

- **四件穿齐才算**：黄金铠甲四件 → 英雄王；骑士王铠甲四件 → 骑士王。混穿或缺一件，两边的能力都不生效，每件只算钻石级护甲。
- **穿齐的瞬间**：英雄王身后闪过一圈金色涟漪、钟鸣，屏幕顶部"英雄王，降临"；骑士王脚下卷起淡青旋风、剑鸣，"骑士王，应召而来"。
- **换装冷却 15 秒**：从一位王退出后，15 秒内不能成为另一位王（换回同一位王不受限），防止"放完 Ea 立刻换装放圣剑"。
- **冷却不会因换装重置**：所有冷却按游戏时间走，脱下铠甲期间照常倒计时。
- **铠甲极难破坏**：无耐久、不能附魔；游戏规则 `fatekings:keep_regalia`（默认开）让铠甲在死亡时留在身上。
- 脱甲的瞬间：蓄力中的技能取消，Ea 回到宝库，维摩那缓慢降落后收回，战马化为光点，冲锋立即停止。

**两位王的基础属性**（和原咒术 Mod Ⅴ 阶段同档并再高一档）：

| 属性 | 英雄王 | 骑士王 |
|---|---|---|
| 最大生命 | 40 颗红心 | 40 颗红心 |
| 金心 | 30 颗（先扣金心，10 秒不受伤后缓慢恢复） | 30 颗 |
| 护甲 / 韧性 | 30 / 20 | 30 / 20 |
| 徒手伤害（空手时） | 24 | 24 |
| 击退抗性 | 100% | 100% |
| 移动速度 | +20% | +30% |
| 承受伤害（默认） | 1%：原版、第三方 Mod、环境、无来源 | 1% |
| 例外：宿傩 Mod 的一切来源、另一位王 | 10% | 10% |
| 摔落 | 免疫 | 免疫 |
| 特殊移动 | **双击空格飞行**（常驻） | **空格 = 温斯顿式魔力放出跳跃**；移动时水面奔跑 |

承伤按"除外"逻辑写：默认 1%，只有宿傩 Mod 的实体（五条悟、宿傩、魔虚罗及其术式实体）、咒术路线玩家和另一位王（玩家或 NPC）是 10%。`/kill` 和虚空伤害不减免。

被动：
- **飞行**：穿齐黄金铠甲即可像创造模式一样双击空格起飞 / 降落，常驻，不需要任何道具；速度略快于创造飞行。切换游戏模式、重生、重登后自动恢复；脱甲时只收回本 Mod 给的飞行权限。
- **全知全能之星**：准星指向 64 格内的生物时，显示名字、生命、护甲和所属一方（五条悟一方 / 宿傩一方 / 魔虚罗 / 英雄王 / 骑士王 / 原版），不透视墙体。
- **黄金律**：击杀生物额外掉金粒，概率掉金锭。
- **自动防御宝具**：血量低于一半时展开三枚金盘 10 秒，把 20 格内飞来的投射物用金色电弧击落（挡不住无下限、世界斩和风王铁锤），冷却 45 秒。

### 骑士王 · 阿尔托利亚

所有主动技能都在**誓约胜利之剑**一把剑上：

| 操作 | 技能 | 冷却 | 效果 |
|---|---|---|---|
| 左键 | 挥砍·风王结界 | — | 30 伤害（剑身显现时 39），攻击距离 +1.5 格，身前 3 格扇形风刃横扫。刀路跟随鼠标甩动的方向（横扫 / 斜劈 / 竖劈 / 上挑，8 个方向）；鼠标不动时按连招循环 |
| 左键（剑身显现时） | 金色剑气 | 两刀间隔 0.3 秒 | 额外射出一道金色新月剑气，倾斜角度与这一刀一致；飞行 28 格，沿途每个生物 24 伤害；地形开关打开时切开沿途可破坏的方块。无下限照常挡住 |
| 短按右键 | 风王铁锤 | 6 秒 | 40 格气流炮，沿途 25 伤害并击飞 10 格以上；吹灭火焰、吹散掉落物（地形开关开时吹落树叶和高草）；之后剑身显现 **10 秒** |
| 潜行+右键 | 魔力放出·冲锋 | 3 秒 | 沿视线冲刺约 14 格，路径 20 伤害并撞开，空中可再冲一次 |
| 按住右键 ≥1.5 秒后松开 | 真名解放·誓约胜利之剑 | 60 秒 | 蓄力时风王结界炸开、星之光汇聚、金色光柱冲天（128 格可见）；释放金色光之斩击，射程 160 格、宽 5 格（蓄满 4 秒 9 格），留下发红冷却的焦土沟。原版一切生物（含首领、无路线普通玩家）**即死**；魔虚罗即死；五条悟打残不致死；其他 Mod 角色 90–100 再折算。之后**魔力枯竭 5 秒** |

- 剑的贴图有三种状态：骑士王手中是**风王结界**（只有护手握柄，剑身是流动的风纹）；风王铁锤后、魔力枯竭时、别人手中是**显现**；蓄力时是**真名解放**（金白光流）。
- 蓄力中被近身连打 3 下会被打断（冷却只算一半）；骑乘时不能蓄力（需要双手）。

被动：
- **遥远的理想乡**：① 脱战 5 秒后每秒回 2 颗心、战斗中每秒 0.5 颗，每 3 秒清除中毒 / 凋零 / 虚弱 / 缓慢等，饥饿值不下降；② 受到致命伤时保留 1 颗心、无敌 3 秒并在 5 秒内回复 20 颗心（240 秒冷却）；③ 被天地乖离开辟之星、世界斩、茈、另一把誓约胜利之剑或任何一击掉一半以上生命的攻击命中时，自动完全展开光片穹顶，3 秒免疫一切，圣剑冷却清零、5 秒内可再放一次（300 秒冷却）。**领域不会触发它。**
- **直感**：原版投射物 50%、王之财宝单发 35% 侧身躲开；64 格内有人准备王律键开锁、Ea、另一把圣剑、世界斩、茈或领域展开时，屏幕边缘出现金色箭头（只预警不免疫）。
- **对魔力**：原版的瞬间伤害、中毒、虚弱、缓慢、漂浮、失明、黑暗、挖掘疲劳和唤魔者尖牙、伤害药水都对她无效；咒术不是魔术，咒术一方的效果照常生效。
- **魔力放出**：近战命中迸出蓝白火花，击退 +20%。
- **骑乘**：能直接骑上未驯服的马、驴、骡、骆驼并操控（不需要鞍），坐骑移速 +50%。
- **湖中仙女的加护**：移动时可以在水面奔跑（疾跑或走动都行），停下会沉。
- **骑士王的战马**（道具）：召唤披银蓝马铠的白色战马，约为最快马的 1.5 倍速，能跟她一起在水面奔跑；累计 60 伤害化为光点，冷却 30 秒。

### 宿敌对决

- 两个 NPC 在 48 格内互相看见就开战。英雄王先用天之锁束缚她（"Saber，成为本王的妻子吧。"），被她打中一次就认真；只要血量低于一半或挨过一次圣剑，就开锁拔 Ea。骑士王一看到他就全力以赴，直感察觉到开锁就拉开距离蓄力迎击。
- **宝具对撞**：Ea 与圣剑在 3 秒内相向发射且路径相交时，在交点僵持 3 秒（白色能量球、天空一半红黑一半金色）。第 2 秒定胜负：骑士王的理想乡**就绪** → 理想乡展开挡下全部 Ea，她获得反击（下一发圣剑对英雄王伤害翻倍），英雄王僵直 1.5 秒（"……Saber——！"）；理想乡**冷却中** → Ea 压过圣剑，她承受剩余威力的一半。玩家之间同样适用。

### 刷怪蛋 NPC

创造物品栏「Fate · 英雄王与骑士王」分页里有两枚刷怪蛋。NPC 的能力和穿齐铠甲的玩家一样，但：

- **血量 200**（金心 150）。玩家的血量不变，玩家对 NPC 的伤害 ×2.5 作为补偿，所以打 NPC 的节奏和 1.0.0 一样。
- 两个 NPC 打宿傩 Mod 的 NPC 时伤害 ×2，足以和五条悟、宿傩抗衡；穿齐铠甲的玩家同样享有这个 ×2（见下文"与咒术回战 Mod 同装"）。无下限、魔虚罗适应等机制不变。

- **吉尔伽美什**：敌对生物（会被无量空处定住，五条悟 NPC 会主动攻击他）。交战时浮在半空，比目标高 5–7 格，俯视着绕目标游移；脱战后缓缓落地。傲慢（几乎不动，随手丢 1–3 件宝具，不闪避）→ 不悦（累计受伤 40 或被"不配的东西"打中：8–15 道涟漪、天之锁）→ 认真（血量低于一半，或被够格者先手：30–60 道齐射、环形包围、束缚、拉开距离）→ Ea（只对够格者，且需要血量低于三分之一 / 被无下限挡住 10 秒 / 魔虚罗适应了宝具 / 对方开了领域之一；180 秒冷却，每场最多两次）。对普通怪物最多只到不悦。放完 Ea 有 8 秒宝库整理。只攻击惹他的人、16 格内的敌对怪物，会主动挑衅五条悟和宿傩 NPC。**不攻击没有战斗能力的对象**：村民、未被激怒的动物、幼年生物、创造 / 旁观模式玩家、手里没拿武器的普通玩家；被他们打了也只嘲讽一句（"杂种，连武器都不拿……"），不还手。
- **阿尔托利亚**：骑士之礼（开战前行礼，正面冲锋，保护附近村民和玩家）→ 全力（强敌或血量低于 70%：风王铁锤、冲锋、远跳）→ 真名解放（对手是强敌且交战 8 秒 / 对手先放大招或开领域 / 原版首领一照面 / 自身低于一半 / 周围 8 只以上敌对怪物 / 理想乡反击；NPC 冷却 90 秒）→ 背水一战（低于 25%：剑身常驻显现，圣剑 45 秒）。发射前检查射线，路径上有村民、铁傀儡、宠物或床 / 箱子 / 工作台时改为斜上方发射，实在不行改用风王铁锤。不主动打五条悟；打残他之后 12 秒内不再出手。
- 两人都会说台词（FGO 日语原声 + 中文字幕显示在动作栏）。

### 与「咒术回战：五条悟 × 宿傩」Mod 同装

不装它本 Mod 也能独立运行；装了以后自动启用以下规则：

| 规则 | 说明 |
|---|---|
| 承伤 | 两位王被咒术角色（五条悟、宿傩、魔虚罗、术式实体、咒术路线玩家）打承受 10%，咒术角色被两位王打也承受 10%；同时是咒术 Ⅴ 阶段又穿着铠甲时取更有利的那个，不叠乘 |
| 王的伤害加成 | 两位王（NPC 或穿齐铠甲的玩家）打宿傩 Mod 的 NPC（五条悟、宿傩、魔虚罗）时伤害 ×2，宝具、剑气、投射物和徒手都算。原因是对方术式无视护甲，而我方攻击会被护甲削减。打咒术路线玩家不加成 |
| 属性叠加 | 生命、金心、护甲、徒手伤害取较高值，不相加 |
| 无下限 | 两位王的一切攻击都会被挡住，只有**天地乖离开辟之星**和**誓约胜利之剑**直接穿透（双方看到"无下限被「乖离剑」撕裂 / 被「星之光」贯穿"） |
| 魔虚罗 | Ea 和圣剑命中即死，不解析、不适应、无视不屈之躯；王之财宝和风王铁锤会被正常适应并反弹 |
| 五条悟 | 圣剑把他打到 1 颗心并清空金心，12 秒"圣剑之创"（移速、伤害减半，回复减半，不能展开领域）；12 秒内这名骑士王无法杀死他；圣剑本身绝不致死 |
| 天之锁 | 被缚的咒术角色不能施放术式、空间瞬移或远跳 |
| 领域 | 无量空处同样定身两位王（吉尔伽美什 NPC 作为敌对生物也会被五条悟的领域和 NPC 盯上）；理想乡不会为领域展开；对魔力不影响领域 |
| 地形开关 | 两个 Mod 共用：`/fate terrain off` 会同时关掉对方的开关 |

所有道具都在创造物品栏「Fate · 英雄王与骑士王」分页，没有合成配方。

|---|---|
| `fatekings:golden_crown` / `golden_chestplate` / `golden_greaves` / `golden_sabatons` | 黄金铠甲四件 |
| `fatekings:gate_of_babylon` / `bab_ilu` / `enkidu` / `vimana` / `treasury_elixir` | 英雄王的宝具（`ea` 只能用王律键取出） |
| `fatekings:knight_ribbon` / `knight_breastplate` / `knight_skirt` / `knight_boots` | 骑士王铠甲四件 |
| `fatekings:excalibur` / `warhorse` / `knight_barding` | 誓约胜利之剑、战马、马铠 |
| `fatekings:gilgamesh_spawn_egg` / `artoria_spawn_egg` | 刷怪蛋 |
| `fatekings:grail_mud` | 圣杯之泥：一击击败两位王的 NPC（单人世界或管理员） |

按键：全部用原版按键——右键（短按 / 按住 / 潜行+右键）、左键（骑士王挥砍，显现时出剑气）、空格（英雄王双击飞行，骑士王魔力放出跳跃）。

命令（管理员）：

| 命令 | 作用 |
|---|---|
| `/fate terrain on\|off` | 地形破坏开关（Ea 的时空断层、圣剑焦土沟、风王铁锤吹落树叶） |
| `/fate cooldowns reset [玩家]` | 清空冷却与宝库整理 / 魔力枯竭 |
| `/fate cast <技能> [蓄力 tick]` | 调试用：以执行者身份直接施放 |

客户端命令：`/fateclient hud|lowfx|reduceshake|noflash true|false`。

## ⚙️ 配置与游戏规则

- `config/fatekings-server.json`：`terrainDestruction`（默认 `true`）。
- `config/fatekings-client.json`：`hudVisible`、`lowFx`（减少特效：Ea 只留光束和裂缝轮廓、不切云、不暗天）、`reduceShake`（震动减到四分之一）、`noFlash`（关闭全屏闪光）。
- 游戏规则：`fatekings:excalibur_boss_instakill`（默认开，关掉后原版首领只受大量伤害）、`fatekings:knight_spares_pets`（默认开，圣剑不伤发动者的宠物）、`fatekings:keep_regalia`（默认开）。

## ❓ 常见问题

- **左键没有剑气？** 剑气只在剑身显现时出现：先短按右键放风王铁锤，之后 10 秒内挥砍。
- **穿上铠甲没反应？** 必须四件都是同一套；刚从另一位王脱下时有 15 秒换装冷却（动作栏会提示剩余秒数）。
- **右键宝具提示"宝库不会为凡人开启"？** 没穿齐黄金铠甲。骑士王的剑提示"圣剑只回应王的召唤"同理。
- **Ea 不见了？** Ea 只能留在英雄王主手 30 秒；切换快捷栏、丢出、放进箱子或到时都会回到宝库，王律键回到原位。
- **按空格没有正常跳？** 骑士王的空格是魔力放出跳跃；潜行+空格是普通跳。
- **飞不起来？** 需要穿齐黄金铠甲，双击空格（1.0.1 起切换模式 / 重生后也会自动恢复）。
- **画面太晃 / 太闪？** 用 `/fateclient reduceshake true`、`/fateclient noflash true`、`/fateclient lowfx true`。

## 🛠️ 从源码构建

需要 JDK 25。

```bash
git clone https://github.com/RoyceBella-commits/fate-kings.git
cd fate-kings
./gradlew build
```

产物在 `build/libs/`，使用不带 `-sources` 后缀的那个 JAR。构建会跑 390 余项规则检查和 19 个服务端 game test。如果把[宿傩 Mod](https://github.com/RoyceBella-commits/jjk-gojo-sukuna) 克隆到同级目录 `../jjk-gojo-sukuna` 并先构建它，兼容规则也会在测试里真实运行（`-PnoJjk` 可关闭）。更新内容见 [CHANGELOG](CHANGELOG.md)。
